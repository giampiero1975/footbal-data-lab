Prima volta? Apri la guida rapida
  1. Inserisci il token RAG API: non è la password SSH e non è la chiave Groq.
  2. Puoi incollare il solo valore oppure l'intera riga restituita dal comando amministrativo: il pannello rimuove automaticamente nome, virgolette e spazi.
  3. Premi Connetti; il token resta soltanto nella memoria della scheda.
  4. Scrivi una domanda tattica completa e inviala.
  5. Leggi separatamente bozza RAG, revisione Groq, risposta migliorata e fonti.
Amministratore: recuperare il token

grep '^RAG_API_.*TOKEN=' ~/.config/football-data-lab/rag-api.env

Non pubblicarlo e non confonderlo con la password dell'utente football.

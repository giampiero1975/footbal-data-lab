Come usare il pannello
  1. Inserisci il token RAG API nel campo sotto: non è la password SSH.
  2. Premi Connetti e attendi il messaggio verde “Connesso”.
  3. Scrivi una domanda tattica e premi Invia domanda. La risposta può richiedere alcuni minuti.
  4. Consulta le fonti sotto la risposta; puoi lasciare un feedback o esportare il risultato.

Il token rimane soltanto nella memoria di questa scheda: dopo un aggiornamento o la chiusura della pagina va inserito di nuovo.

Amministratore: dove recuperare il token

Collegati alla VPS come utente football ed esegui:
grep '^RAG_API_.*TOKEN=' ~/.config/football-data-lab/rag-api.env
Copia soltanto il valore dopo il segno =. Non condividere il token e non inserire la password SSH.
